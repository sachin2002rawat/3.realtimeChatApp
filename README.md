# Realtime Chat Application  

## Live Project
[View Live Project](https://realtimechatapp-a0ip.onrender.com/login)


A realtime chat application built with **MongoDB, Express.js, React.js, and Node.js (MERN)**.  
It uses **Socket.IO** for live communication, **JWT authentication** with role-based access, and **Redux Toolkit** for efficient state management.  

## Features  
- 🔐 Secure authentication with JWT  
- 👥 Role-based authorization via middleware  
- 💬 Real-time messaging with Socket.IO  
- ⚡ Scalable front-end with Redux Toolkit  
- 🗄️ MongoDB for database storage
